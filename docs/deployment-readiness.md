# 抖音在线版部署说明

已选架构：Vercel 静态网页 + 个人 DeepSeek 请求转发 + 用户本机浏览器扩展。**没有云数据库、网站账户或 Windows 微信端依赖。**

## 数据边界

| 内容 | 位置与边界 |
| --- | --- |
| 素材、指标、采集任务、关键词设置 | 扩展 IndexedDB；每个浏览器配置文件独立 |
| 抖音登录状态 | 使用者自己的抖音页面；本站不读取 Cookie |
| DeepSeek Key | 网页内存；仅请求转发，刷新清除，不写备份 |
| 视频文件 | 用户手动选择本机文件预览；不上传、不自动下载 |
| JSON / CSV | 用户主动下载到自己的电脑 |

扩展只自动拥有抖音权限。网站需用户点击扩展弹窗授权精确 HTTPS origin；网页桥接检查来源，扩展再次校验已授权 origin。没有任意脚本/网络/文件读取接口。所有获授权的站点共享同一浏览器扩展素材库，应只授权可信网站，可随时撤销。Key 不通过扩展桥接。

## 发布范围

- 仓库只含应用源码、测试、文档和构建配置，不含课程/商品资料、.env 文件、数据库、浏览器资料、日志、截图或下载视频。
- 在线 UI 只显示抖音。保留旧 Node 多平台代码是兼容需要，不部署其服务或开放调试端口。
- pnpm build:web 生成在线页面和可下载助手 ZIP，不覆盖本机 dist。
- vercel.json 指定在线构建、静态目录与 DeepSeek 云函数。
- DeepSeek 必须由调用者自带 Key，云函数强制禁用本机/环境配置读取，限制请求格式、正文大小、同源访问，错误不回显输入。

## 使用与可靠性

- 未安装/未授权扩展时明确提示并禁用采集，不假装空结果成功。
- 每词按原词搜索，核验“最多点赞”、时间范围后才读取；筛选失败应报错。
- 普通模式不强制 AI 证据或完整指标。AI 模式才进详情核验。
- 登录与验证码只提示用户完成，不自动解决。
- 已接收素材增量保存；浏览器/扩展服务重启后标记未完成任务中断，保留素材，可重试去重。
- 平台结构、风控和账号结果会变化。自动化测试/构建通过不等同于所有真实账号都能长期稳定采集。
- 没有云同步；卸载或清理扩展前必须备份。已下载本地备份由用户自行妥善保管。

## 测试层次

测试覆盖服务层、IndexedDB 重启、任务失败、关键词来源、普通/AI 模式、消息来源权限、备份校验、个人 Key 隔离、在线 UI 与构建产物。发布后检查网页、静态资源、ZIP、DeepSeek 状态和错误接口。真实抖音登录/验证码及平台数据采集需要已授权的浏览器环境另行验证，不得用伪造素材声称实测成功。
