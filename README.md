# 全域短视频投流情报台

按自己输入的关键词研究抖音公开热门视频：素材数据库、分主题热榜、投流分析。不会自动加入母婴词或替换你的搜索词；DeepSeek 扩词只有点选后才加入队列。

## 在线版：网站 + 本机浏览器扩展

网站由 Vercel 托管。**不使用云数据库，不要求网站账号**；素材、搜索设置和任务存于使用者浏览器扩展的 IndexedDB。不同电脑/浏览器不自动同步。只支持桌面 Chrome / Edge 的抖音公开搜索；在线版不包含微信和小红书。

1. 打开网站，在「本机助手与数据」下载助手 ZIP 并解压到固定文件夹。
2. 打开浏览器扩展管理，启用「开发者模式」，点击「加载已解压的扩展」，选择解压目录。当前尚未上架扩展商店。
3. 回到网站，点击工具栏的助手图标，点击「授权当前网站」，同意权限后刷新网页。
4. 每输入一个关键词按回车，确认队列、发布时间和「仅采集 AI 生成视频」开关，再开始搜索。
5. 扩展逐词打开抖音、应用「最多点赞」筛选。登录或安全验证必须由你在抖音页面完成；工作台会提示等待。不要关闭任务标签页。

「仅采集 AI 生成视频」默认关闭：普通模式不因缺少 AI 声明或收藏/评论指标而隐藏结果；开启后进入详情页核验声明。声明是可追溯证据，不代表本工具保证内容完全由 AI 制作。页面改变、平台限流或验证可能导致暂停/失败，不能承诺抓到全网所有爆款。

### 数据、备份和视频

- 未读到或未公开的指标保持“—”，不会填成 0。系统研究分不是平台官方热度，不是实际广告转化/ROI。
- “本次关键词结果”按实际采集来源筛选；“历史素材库”查看此前所有主题。
- 可导出 CSV、导出本机 JSON 备份、合并备份。卸载扩展/清理浏览器数据/换电脑前先备份。
- 扩展重启后保留已保存素材，未完成任务标为中断，可重新搜索去重更新；不承诺从任意页面步骤断点续跑。
- 在线版只保存公开素材记录、链接与可见指标，不自动下载视频。拥有使用权限的视频可自行下载，再通过「预览本地视频」选择播放，不上传文件。
- 各浏览器配置文件彼此独立；同一配置文件内所有获你授权的网站都可访问此扩展的本地素材库。只授权你信任的网站，扩展弹窗可撤销授权。

### 个人 DeepSeek Key

点击关键词区「设置 / 切换 Key」输入自己的 Key。Key 仅保留在当前页面内存，刷新或关闭后清除；**不写入本机素材备份或云端数据库**。请求通过本站 HTTPS 接口转发到 DeepSeek 官方，验证仅查模型列表；费用归所用 Key 的账户。不设置 Key 也可按原词搜索。在线服务永不回退使用站主环境密钥。

## 本机 Node 版本（保留兼容）

本机版本仍可使用原有多平台代码、SQLite 和授权媒体流程，与在线扩展的数据相互独立。不得把无鉴权本地 API 直接暴露公网。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

打开 http://127.0.0.1:4318 。Windows 也可使用「启动工作台.cmd」/「停止工作台.cmd」。数据库、采集浏览器登录资料、日志、下载视频均仅存本机，不纳入仓库。原 browser-helper 是连接本地服务的旧助手，不等同于在线版 3.0.0 助手。

## 开发与部署

Node.js 24，pnpm 11.19.0。

```sh
pnpm test
pnpm build                 # 本机 Node 版本输出 dist
pnpm build:extension       # build/local-extension + public/downloads/douyin-helper.zip
pnpm build:web             # 在线版输出 dist-web，自动打包扩展
```

Vercel 使用仓库内 vercel.json，安装 pnpm install --frozen-lockfile，构建 pnpm build:web，静态目录 dist-web。仅 /api/deepseek/* 是云函数；素材接口走用户已授权的扩展，不会请求 localhost 或云数据库。不要给公共部署配置站主 DeepSeek Key。

首次安装扩展需要用户操作；扩展商店发布、商店签名更新和真实账号下的长期平台兼容性测试不包含在网站部署本身中。若平台页面更新，需更新助手并重新加载。

更多边界见 [部署说明](docs/deployment-readiness.md) 和 [扩展协议](docs/local-extension-protocol.md)。本工具不绕过验证码、账号权限、付费内容或平台访问控制；请仅在获得必要权限且符合平台规则时使用。
